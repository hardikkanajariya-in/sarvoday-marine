# Website Development Quotation

**Project:** Sarvoday Marine Services Pvt. Ltd. – Static Corporate Website  
**Quotation Amount:** ₹10,000 + GST  
**Quotation Type:** Static Website Development  
**Prepared For:** Sarvoday Marine Services Pvt. Ltd.

---

## 1. Project Overview

We propose to design and develop a **responsive static corporate website** for Sarvoday Marine Services Pvt. Ltd., based on the website roadmap and sitemap shared by the client.

The website will present Sarvoday Marine Services and its Cabotage Logistics Solutions offering under the same Sarvoday brand, with a professional corporate layout suitable for desktop, tablet, and mobile devices.

The website will be developed as a **static website without CMS, database, or administrative panel functionality**.

---

## 2. Website Pages / Scope

The quoted price includes development of the following website sections and pages:

### Home
- Hero/banner section
- Company introduction
- Services overview
- Trust/statistics section
- Working process section
- Testimonials / client section, where content is provided
- Call-to-action sections
- Footer

### About Us
- Company profile / history
- Leadership & team
- Vision & values
- Our Expertise

### Services
Services overview page with the following individual service pages:

1. Marine Inspections
2. Liquid Cargo Inspections
3. General Cargo Inspections
4. Project & ODC
5. Container Inspections
6. Cabotage Logistics Solutions

Each service page will contain the relevant service information supplied by the client.

### Locations
- Head Office
- Branch office listing
- PAN-India service coverage information
- Google Maps integration

### Contact Us
- Contact information
- Address details
- Phone and email
- Contact / enquiry form
- WhatsApp contact button, where applicable

---

## 3. Design & Development Features

The website package includes:

- Responsive design for desktop, tablet, and mobile
- Corporate and clean visual layout
- Sarvoday brand colors and logo integration
- Basic page animations / interactive effects
- Website navigation and internal links
- Service enquiry call-to-action
- Google Maps integration
- WhatsApp click-to-chat integration
- Basic contact/enquiry form
- Basic SEO meta title and description setup
- Basic browser compatibility testing
- Website deployment assistance

---

## 4. Static Website Limitation

This quotation is specifically for a **static website**.

The following dynamic features mentioned in the original roadmap are **not included**:

- CMS / WordPress or other content management system
- Admin / back-office panel
- Database
- User login system
- Role-based access
- Admin management of services or branches
- Admin enquiry dashboard
- Database storage of form submissions
- Dynamic news/update management
- Admin-editable statistics or counters
- Custom backend development

Any future content changes after final delivery will require developer assistance.

- Logo and other brand assets
